Medical Management System

📌 Project Overview

The Medical Management System is a simple system designed to manage patient and doctor information, appointments, medical history, and prescription details.

This project demonstrates the basic working of a medical management system using an ER Diagram, Algorithm, and Flowchart.

🎯 Objectives

- Store patient details.
- Store doctor details.
- Book and manage appointments.
- Record patient's medical history.
- Store prescription details.
- Display and manage important medical information.

🧩 Main Modules

1. Patient Details

Stores:

- Patient ID
- Name
- Age
- Gender
- Phone
- Address

2. Doctor Details

Stores:

- Doctor ID
- Name
- Specialization
- Phone
- Department

3. Appointment

Stores:

- Appointment ID
- Patient ID
- Doctor ID
- Appointment Date
- Appointment Time
- Status

4. Medical History

Stores:

- History ID
- Patient ID
- Diagnosis
- Previous Illness
- Allergies
- History Date

5. Prescription Details

Stores:

- Prescription ID
- Patient ID
- Doctor ID
- Appointment ID
- Medicine Name
- Dosage
- Duration
- Prescription Date

The ER design defines relationships such as one patient having many appointments and many medical-history records, while doctors can have many appointments and create many prescriptions.

🔄 System Flow

The basic system flow is:

Start → Enter Patient Details → Enter Doctor Details → Book Appointment → Check Appointment Availability → Confirm Appointment → Record Medical History → Doctor Consultation → Enter Prescription Details → Display/Store All Details → End

This flow follows the modules and decision process specified in the project flowchart.

📝 Algorithm

1. Start.
2. Enter patient details such as Patient ID, Name, Age, Gender, and Contact Number.
3. Enter doctor details such as Doctor ID, Name, Specialization, and Contact Number.
4. Book an appointment by entering the appointment date and time.
5. Check and record the patient's medical history.
6. Doctor examines the patient and provides diagnosis.
7. Enter prescription details such as medicines, dosage, and duration.
8. Store patient, doctor, appointment, medical history, and prescription details.
9. Display appointment and prescription details.
10. End.

The algorithm is designed in simple numbered steps for BCA students.
